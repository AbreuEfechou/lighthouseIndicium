# Relatório de Análise Exploratória dos Dados (EDA)

## Introdução
Este relatório apresenta os principais insights e visualizações geradas a partir da análise exploratória dos dados contidos no arquivo `desafio_indicium_imdb.csv`. O objetivo é entender as características dos filmes, suas relações e padrões que podem ser observados nos dados.

## Descrição dos Dados
O conjunto de dados contém informações sobre filmes, incluindo as seguintes colunas:
- **Título**: Nome do filme.
- **Ano de Lançamento**: Ano em que o filme foi lançado.
- **Gênero**: Gêneros aos quais o filme pertence.
- **Sinopse**: Breve descrição do enredo do filme.
- **Nota do IMDb**: Avaliação do filme no IMDb.
